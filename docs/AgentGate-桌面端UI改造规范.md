# AgentGate 桌面端 UI 改造规范

> 文档版本：1.0  
> 评估日期：2026-08-20  
> 适用范围：桌面端 Web，建议支持宽度 `1280px` 及以上  
> 不包含：移动端、平板端、后端业务逻辑和数据结构调整

## 1. 改造目标

AgentGate 是面向 Agent 评估、回归测试和质量管理的工作型后台。本次改造应保持界面克制、专业、易扫描，优先提升以下方面：

1. 统一登录、未登录、加载、空数据和错误状态。
2. 强化页面与操作层级，让用户能在 3 秒内找到主要任务。
3. 降低设置页和资源库的信息密度。
4. 统一颜色、字体、间距、控件与交互状态。
5. 提升品牌一致性，消除登录页与主应用之间的视觉割裂。

当前桌面端综合评估约为 **7.3 / 10**。完成本规范中的 P0、P1 项后，目标为 **8.2–8.5 / 10**。

---

## 2. 设计原则

### 2.1 工作效率优先

- 页面第一视觉重点必须是当前页面的主要任务。
- 一个区块最多保留一个主按钮。
- 次要操作使用次级按钮、文字按钮或更多菜单。
- 数据区尽量安静，仅用颜色表达成功、警告、失败、运行中等语义状态。

### 2.2 状态必须完整

每个数据模块都必须设计以下状态：

- 初次加载
- 加载成功
- 空数据
- 加载失败
- 权限不足
- 登录过期
- 操作进行中
- 操作成功

禁止让界面长时间停留在无解释的“加载中…”。

### 2.3 避免卡片套卡片

- 页面区块可以使用白色卡片。
- 卡片内部的空状态、表单和列表不再增加第二层卡片。
- 使用留白、分隔线或浅色状态区域组织内部内容。

## 4. 全局页面骨架

### 4.1 页面背景

- 主应用背景：`#F6F8FB`。
- 页面最小高度：`100vh`。
- 内容不足一屏时，背景仍应铺满视口。

### 4.2 左侧栏

| 属性 | 规格 |
|---|---|
| 宽度 | 固定 `208px` |
| 定位 | `position: fixed` |
| 高度 | `100vh` |
| 背景 | `#FFFFFF` |
| 右边框 | `1px solid #E4E7EC` |
| 层级 | `z-index: 20` |

侧栏不使用明显阴影。

### 4.3 主内容区

```css
.main {
  margin-left: 208px;
  min-height: 100vh;
  padding: 28px 24px 40px;
}

.main-inner {
  width: min(100%, 1440px);
  margin: 0 auto;
}
```

- 在 `1366px` 宽度下，内容区左右保留 `24px`。
- 在超宽屏下，内容最大宽度为 `1440px`，避免表单和文字无限拉长。
- 页面标题与首个内容区之间保留 `24px`。
- 页面区块之间保留 `16px`。

- 高度 `36px`。
- 左右内边距 `14px`。
- 圆角 `6px`。
- 背景 `#2457E6`。
- 文字白色，字重 `600`。
- 图标 `16px`，图标与文字间距 `8px`。
- 悬停背景 `#1947C9`。
- 按下背景 `#153DAE`。

### 7.2 次级按钮

- 高度 `36px`。
- 白色背景。
- 边框 `1px solid #D0D5DD`。
- 文字 `#344054`。
- 悬停背景 `#F9FAFB`。

### 7.3 危险按钮

- 默认使用白底红字：`#D92D20`。
- 边框 `#FDA29B`。
- 悬停背景 `#FEF3F2`。
- 删除按钮不得与主要按钮拥有相同视觉权重。

### 7.4 图标按钮

- 尺寸 `36 × 36px`。
- 图标 `16px`。
- 无文字时必须提供 Tooltip 和 `aria-label`。
- 使用图标表达编辑、删除、刷新、关闭、更多等操作。

### 7.5 输入框

- 高度 `36px`。
- 左右内边距 `12px`。
- 边框 `#D0D5DD`。
- 圆角 `6px`。
- 文字 `14px`。
- Placeholder 颜色 `#98A2B3`。

聚焦状态：

```css
input:focus,
select:focus,
textarea:focus {
  border-color: #2457e6;
  box-shadow: 0 0 0 3px #dce6ff;
  outline: none;
```

### 7.6 字段结构

字段不得只依赖 Placeholder 表达含义。

```text
字段标签
输入框
帮助说明或错误信息
```

- 标签与输入框间距 `6px`。
- 输入框与帮助说明间距 `6px`。
- 字段之间水平或垂直间距 `16px`。
- 必填标记使用红色 `*`，不要使用整段红色标签。

### 7.7 下拉框

- 与输入框保持相同高度和边框。
- 使用 `ChevronDown` 图标。
- 下拉菜单最大高度 `280px`。
- 选项超过 8 个时提供搜索。
- 无可选项时显示原因，不保留空白菜单。

### 7.8 卡片

- 白色背景。
- 边框 `1px solid #E4E7EC`。
- 圆角 `8px`。
- 内边距 `20px`。
- 阴影 `0 1px 2px rgba(16,24,40,.05)`。
- 卡片标题与正文间距 `12px`。
- 卡片内部不再放置第二张有边框卡片。

### 7.9 Tooltip

- 延迟 `400ms` 出现。
- 深色背景 `#172033`。
- 白色文字 `12px / 18px`。
- 最大宽度 `240px`。
- 用于解释陌生图标或被截断内容，不用于替代常驻字段说明。

## 8. 工作台逐元素规范

### 8.1 页面标题

- 标题：`工作台`。
- 说明：`创建、运行和管理可重复执行的评估方案`。
- 页面标题下方间距 `24px`。

### 8.2 评估方案区

外层卡片：

- 内边距 `20px`。
- 最小高度由内容决定。
- 不设置固定大高度。

标题与工具栏使用同一行：

```text
评估方案                         Agent 筛选  搜索框  新建方案
```

#### 区块标题

- 文字：`评估方案`。
- 字号 `18px / 26px`。
- 字重 `600`。

#### Agent 筛选

- 宽度 `160px`。
- 默认值：`全部 Agent`。
- 前端应保持选中项宽度稳定，避免工具栏位移。

#### 搜索框

- 宽度 `280px`。
- 左侧增加 `Search` 图标。
- Placeholder：`搜索方案或 Agent`。
- 输入后 `300ms` 防抖搜索。
- 有内容时显示清除按钮。

#### 新建方案按钮

- 使用 `Plus` 图标，不使用文本字符 `+`。
- 文案：`新建方案`。
- 作为该区块唯一主按钮。
- 未登录时禁用，Tooltip：`登录后可创建评估方案`。

### 8.3 未登录状态

删除当前卡片内部的虚线框，改为无边框空状态区域。

- 上边框：`1px solid #E4E7EC`。
- 与工具栏间距 `20px`。
- 最小高度 `220px`。
- 内容水平和垂直居中。
- 图标：`LockKeyhole`，`32px`，颜色 `#667085`。
- 图标与标题间距 `12px`。
- 标题：`登录后开始评估`。
- 说明：`登录后可创建评估方案并查看历史运行。`
- 主按钮：`登录`。

禁止出现“通过左下角登录”等位置性文案。

### 8.4 已登录但无方案

- 图标：`ClipboardPlus`。
- 标题：`还没有评估方案`。
- 说明：`创建方案，配置线上评估、回归测试或红队测试。`
- 主按钮：`新建方案`。

### 8.5 方案列表

有数据时使用表格，不使用大量独立卡片。

| 列 | 建议宽度 | 说明 |
|---|---:|---|
| 方案名称 | `26%` | 可点击进入详情 |
| Agent | `18%` | 显示 Agent 名称 |
| 环节 | `18%` | 使用简短标签 |
| 调度 | `14%` | 手动或 Cron 摘要 |
| 最近运行 | `16%` | 日期和时间 |
| 操作 | `8%` | 更多菜单 |

表格行高建议 `52px`。

### 8.6 最近运行区

区块标题行：

- 标题：`最近运行`。
- 说明：`跨方案 · 按时间倒序`。
- 标题与说明间距 `12px`。

表格列：

| 列 | 内容 |
|---|---|
| 方案 | 方案名称 |
| Agent | Agent 名称 |
| 状态 | 成功、失败、运行中、跳过 |
| 得分 | 使用等宽数字 |
| 耗时 | 秒或分钟 |
| 运行时间 | 日期和时间 |
| 操作 | 查看报告 |

无数据时：

- 标题：`暂无运行记录`。
- 说明：`运行评估方案后，记录会显示在这里。`

未登录时：

- 显示登录空状态。
- 不发起需要鉴权的列表请求。
- 不显示永久“加载中…”。

页内导航：

## 12. 加载、空数据和错误状态

### 12.1 加载状态

- 卡片和表格使用骨架屏。
- 骨架使用 `#EAECF0`，动画周期 `1.4s`。
- 表格显示表头和 3–5 行骨架。
- 按钮内操作使用 `16px` Spinner。
- 加载超过 `10秒`时显示：`加载时间较长，请稍候或重试。`

### 12.2 空数据状态

结构：

```text
图标
标题
一句说明
一个主要操作
```

- 图标 `32px`。
- 标题 `16px / 24px`，字重 `600`。
- 说明最大宽度 `420px`。
- 不使用虚线框套在卡片内部。

### 12.3 错误状态

必须回答两个问题：

1. 发生了什么？
2. 用户现在可以做什么？

示例：

```text
评估方案加载失败
无法连接服务，请检查网络后重试。
[重新加载]
```

### 12.4 登录过期

- 页面顶部显示警告条。
- 文案：`登录已过期，当前数据可能不是最新。`
- 操作：`重新登录`。
- 清除“已登录”状态，避免侧栏和正文状态矛盾。
- 禁止继续使用旧缓存冒充最新数据。

### 12.5 成功反馈

- 使用右上角 Toast。
- 默认显示 `3秒`。
- 示例：`配置已保存`、`评估器已创建`、`数据源连接成功`。
- Toast 不遮挡页面主要操作。

## 13. 弹窗、抽屉和确认操作

### 13.1 普通弹窗

- 宽度 `480–640px`。

- 标题区域、内容区域、操作区域清晰分隔。
- 操作按钮右对齐。
- `Escape`关闭。
- 打开后焦点进入弹窗，关闭后返回触发按钮。

### 13.2 右侧抽屉

适用于：

- 查看缓存详情

- 评估器详情

- 取消按钮为默认焦点。
- 删除按钮使用危险样式。
- 对高风险资源可要求输入名称确认。

## 15. 可访问性要求

- 正文和背景对比度达到 WCAG AA。
- 所有可点击元素支持键盘操作。
- 所有交互元素提供清晰的 `focus-visible`状态。
- 图标按钮必须包含 `aria-label`。
- 输入框必须与可见标签关联。
- 错误信息使用 `aria-live`或等效机制。
- 弹窗打开后锁定背景焦点。
- `Escape`关闭弹窗和抽屉。
- 不仅依赖颜色区分成功、失败和警告。
- 动画遵循 `prefers-reduced-motion`。
